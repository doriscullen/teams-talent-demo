## 1. 背景与目标

### 1.1 业务背景

客户在账单日或大额消费后希望将欠款分摊到多个月，降低短期还款压力；当前系统只有全额还款，缺少分期产品。
本期在白金卡/金卡客户中试点 3/6/12 期分期，沉淀分期计划、还款计划与提前结清能力，为后续费率差异化打底。

### 1.2 业务目标（可量化）

| 目标 | 量化指标 |
|------|---------|
| 提升分期渗透率 | 白金卡/金卡客户分期渗透率由 8% 提升至 15%（上线后 90 天统计口径） |
| 增加中间业务收入 | 分期手续费收入月增 12%（对比上线前 3 个月均值） |
| 缩短申请路径 | 申请到建计划耗时 < 3 秒（p95，本地 Compose 基准） |

### 1.3 术语表

| 术语 | 定义 |
|------|------|
| 单笔消费分期 | 以单笔已入账消费为对象，将本金按 3/6/12 期均摊的分期产品 |
| 账单分期 | 以当期账单应还金额为对象，将本金按 3/6/12 期均摊的分期产品 |
| 手续费率 | 月手续费率，按剩余本金逐期计收，3 期 0.60%、6 期 0.55%、12 期 0.50% |
| 尾差 | 本金除以期数后的舍入差额，由最后一期吸收 |
| 去重键 | 客户端生成的业务唯一键（接口字段 `idempotencyKey`），同一键重复提交返回同一结果 |
| 提前结清 | 一次性归还剩余本金并结清分期计划的动作 |

## 3. 范围定义

### 3.1 In-Scope / Out-of-Scope

**In-Scope**

- 单笔消费分期（3/6/12 期）与账单分期（3/6/12 期）。
- 期数、费率、手续费、每期本金与手续费计算与试算。
- 分期计划、还款计划、提前结清。
- 前台入口、计划页、后台查询。
- 与 transaction、account、billing、ledger、notification、audit 的集成。

**Out-of-Scope**

- 商户贴息、零手续费活动、组合分期。
- 逾期罚息与征信报送（沿用现有账单与催收流程）。
- 多币种分期。

### 3.2 假设与依赖

| 编号 | 假设/依赖 | 说明 |
|------|----------|------|
| A-01 | 交易已由 transaction-service 入账并标记 `POSTED` | 分期资格以该状态为前提 |
| A-02 | 账单可分期金额由 billing-service 计算并提供 | 本期不改造账单计算逻辑 |
| A-03 | 额度占用与释放通过 account-service 完成 | 涉及余额的变更不经本服务直写 |
| A-04 | 手续费收入过账到 ledger-service | 会计科目沿用现有手续费科目 |
| A-05 | 通知走 notification-service 模板 | 通知失败不回滚分期主流程 |

### 4.2 详细功能需求

#### REQ-2026-001-01 交易详情「申请分期」入口（REQ-INS-01）

**功能描述**：在交易详情页对满足资格的单笔消费展示「申请分期」按钮；不满足资格时按钮置灰并展示具体原因，避免客户进入后失败。

**字段级需求表**：

| 字段 | 类型 | 必填 | 格式/校验 | 默认值 | 来源 |
|------|------|------|----------|--------|------|
| transactionId | string(20) | 是 | 20 位数字串，必须属于当前登录客户 | 无 | 路由路径参数 |
| transactionAmount | decimal(12,2) | 是 | ≥ 100.00 才展示可用入口 | 交易金额 | transaction-service |
| transactionStatus | string(16) | 是 | 仅 `POSTED` 视为可分期 | `POSTED` | transaction-service |
| installmentEligible | boolean | 是 | true/false，由服务端计算，前端不得推导 | false | transaction-service 分期资格字段 |
| ineligibleReason | string(64) | 否 | 枚举：`AMOUNT_TOO_LOW`/`ALREADY_INSTALLED`/`DISPUTED`/`DELINQUENT` | 空 | transaction-service |

**异常矩阵**：

| 异常场景 | 系统行为 | 错误码 | 用户提示 |
|---------|---------|--------|---------|
| 交易金额 < 100.00 | 按钮置灰，点击无响应 | `INSTALLMENT_NOT_ELIGIBLE` | 「单笔消费满 100.00 元可申请分期」 |
| 交易已分期 | 展示「已分期」徽标，点击跳转计划详情 | `ALREADY_INSTALLED` | 「该交易已分期，查看分期计划」 |
| 交易处于争议中或已逾期 | 隐藏入口 | `INSTALLMENT_NOT_ELIGIBLE` | 「该交易当前状态不支持分期」 |
| 交易不属于当前登录客户 | 返回 404，不泄露交易存在性 | `INSTALLMENT_NOT_FOUND` | 「交易不存在」 |
| transaction-service 超时（> 500ms） | 入口区域展示重试按钮 | `DOWNSTREAM_UNAVAILABLE` | 「分期入口加载失败，请点击重试」 |

#### REQ-2026-001-02 分期试算（REQ-INS-03）

**功能描述**：客户选择 3/6/12 期后实时展示每期本金、每期手续费、首期合计与总手续费；试算不落库，返回试算令牌供提交复用。

**字段级需求表**：

| 字段 | 类型 | 必填 | 格式/校验 | 默认值 | 来源 |
|------|------|------|----------|--------|------|
| accountId | string(20) | 是 | 20 位数字串，归属校验通过 | 当前账户 | 会话上下文 |
| sourceType | string(16) | 是 | 枚举 `TRANSACTION`/`BILL` | 无 | 前端选择 |
| sourceId | string(32) | 是 | 交易号 20 位或账单号 32 位 | 无 | 前端选择 |
| principal | decimal(12,2) | 是 | > 0，且 ≤ 可分期余额；单笔 ≥ 100.00，账单 ≥ 500.00 | 可分期余额 | 前端表单 |
| termMonths | int | 是 | 仅允许 3/6/12 | 6 | 前端选择 |
| monthlyFeeRate | decimal(6,4) | 是 | 3 期 0.0060、6 期 0.0055、12 期 0.0050 | 按期数映射 | installment-service 定价表 |
| firstPeriodTotal | decimal(12,2) | 是 | = 每期本金 + 每期手续费，HALF_UP 2 位 | 计算值 | installment-service |

**异常矩阵**：

| 异常场景 | 系统行为 | 错误码 | 用户提示 |
|---------|---------|--------|---------|
| 期数不在 3/6/12 | 拒绝试算 | `INVALID_TERM` | 「仅支持 3 期、6 期、12 期」 |
| 本金低于起分金额 | 拒绝试算 | `INSTALLMENT_NOT_ELIGIBLE` | 「单笔满 100.00 元、账单满 500.00 元起分」 |
| 本金超过可分期余额 | 拒绝试算，提示最大可分期金额 | `PRINCIPAL_EXCEEDS_LIMIT` | 「最大可分期金额为 X 元」 |
| 试算令牌超过 30 分钟 | 提交时拒绝，要求重新试算 | `PREVIEW_EXPIRED` | 「试算结果已过期，请重新试算」 |
| billing-service 超时（> 800ms） | 返回可重试错误，不缓存结果 | `DOWNSTREAM_UNAVAILABLE` | 「试算失败，请稍后重试」 |

#### REQ-2026-001-03 提交分期（REQ-INS-04）

**功能描述**：确认页完成协议勾选、去重键生成后创建分期计划与还款计划，写审计并发送通知；任一下游失败不产生「已扣费但无计划」的状态。

**字段级需求表**：

| 字段 | 类型 | 必填 | 格式/校验 | 默认值 | 来源 |
|------|------|------|----------|--------|------|
| idempotencyKey | string(64) | 是 | 客户端生成，全局唯一，30 分钟内重复提交返回原计划 | 无 | 前端 |
| accountId | string(20) | 是 | 与登录客户归属一致 | 当前账户 | 会话上下文 |
| principal | decimal(12,2) | 是 | > 0；与试算令牌金额一致 | 试算值 | 前端表单 |
| termMonths | int | 是 | 仅允许 3/6/12 | 试算值 | 前端选择 |
| previewToken | string(64) | 是 | 未过期，且金额与期数与试算一致 | 无 | 试算响应 |
| agreementAccepted | boolean | 是 | 必须为 true | false | 前端勾选 |
| planStatus | string(16) | 是 | 初始 `ACTIVE` | `ACTIVE` | installment-service |

**异常矩阵**：

| 异常场景 | 系统行为 | 错误码 | 用户提示 |
|---------|---------|--------|---------|
| 同一去重键重复提交 | 返回首次创建的计划（HTTP 200），不重复扣费 | 无（去重命中） | 「分期已提交成功，正在跳转计划」 |
| 交易/账单已存在生效计划 | 拒绝创建 | `ALREADY_INSTALLED` | 「该交易已分期，请查看分期计划」 |
| 未勾选协议 | 拒绝提交 | `AGREEMENT_REQUIRED` | 「请先阅读并同意分期协议」 |
| previewToken 过期或金额不一致 | 拒绝提交，回到试算步骤 | `PREVIEW_EXPIRED` | 「试算结果已变化，请重新试算」 |
| ledger-service 过账失败 | 回滚计划与还款计划，不留半完成状态 | `DOWNSTREAM_UNAVAILABLE` | 「提交失败，本次未产生分期，请重试」 |
| 计划写入与账户额度占用不一致 | 事务回滚并写告警审计 | `DOWNSTREAM_UNAVAILABLE` | 「提交失败，请稍后重试」 |

#### REQ-2026-001-04 我的分期（REQ-INS-05）

**功能描述**：客户查看本人账户下的分期列表与详情，包含还款计划、剩余本金、期数进度；分页返回，越权访问一律 404。

**字段级需求表**：

| 字段 | 类型 | 必填 | 格式/校验 | 默认值 | 来源 |
|------|------|------|----------|--------|------|
| accountId | string(20) | 是 | 归属校验通过 | 当前账户 | 会话上下文 |
| status | string(16) | 否 | 枚举 `ACTIVE`/`SETTLED`/`CANCELLED` | 全部状态 | 前端筛选 |
| page | int | 否 | ≥ 1 | 1 | 前端分页 |
| size | int | 否 | 1–100 | 20 | 前端分页 |
| remainingPrincipal | decimal(12,2) | 是 | ≥ 0，HALF_UP 2 位 | 计算值 | installment-service |
| paidPeriods / termMonths | int / int | 是 | paidPeriods ≤ termMonths | 0 / 期数 | installment-service |

**异常矩阵**：

| 异常场景 | 系统行为 | 错误码 | 用户提示 |
|---------|---------|--------|---------|
| 查询非本人账户的分期 | 返回 404 | `INSTALLMENT_NOT_FOUND` | 「未找到分期记录」 |
| size > 100 或 page < 1 | 参数校验失败 | `INVALID_PARAMETER` | 「分页参数不合法」 |
| status 传入未知枚举值 | 参数校验失败 | `INVALID_PARAMETER` | 「筛选条件不合法」 |
| 计划下还款计划缺失 | 返回计划并标记 `SCHEDULE_INCONSISTENT` 告警 | `SCHEDULE_INCONSISTENT` | 「还款计划加载不完整，请联系客服」 |

#### REQ-2026-001-05 提前结清（REQ-INS-06）

**功能描述**：客户在计划详情发起提前结清，系统试算剩余本金、手续费减免与违约金，确认后结清计划、释放额度并生成调整分录。

**字段级需求表**：

| 字段 | 类型 | 必填 | 格式/校验 | 默认值 | 来源 |
|------|------|------|----------|--------|------|
| planId | string(32) | 是 | 存在、`ACTIVE`、属于当前客户 | 无 | 路由路径参数 |
| settlementPrincipal | decimal(12,2) | 是 | = 剩余本金，≥ 0 | 剩余本金 | installment-service |
| feeRebate | decimal(12,2) | 是 | ≥ 0，按减免策略计算（策略待定价确认） | 0.00 | 定价策略 |
| penaltyFee | decimal(12,2) | 是 | = 剩余本金 × 1%，HALF_UP 2 位 | 计算值 | 定价策略 |
| settlementTotal | decimal(12,2) | 是 | = 剩余本金 + 违约金 − 手续费减免 | 计算值 | installment-service |
| settlementIdempotencyKey | string(64) | 是 | 唯一，重复提交返回首次结果 | 无 | 前端 |

**异常矩阵**：

| 异常场景 | 系统行为 | 错误码 | 用户提示 |
|---------|---------|--------|---------|
| 计划已结清或已取消 | 拒绝结清 | `SETTLEMENT_NOT_ALLOWED` | 「该计划已结清，无需重复操作」 |
| 计划不存在或非本人 | 返回 404 | `INSTALLMENT_NOT_FOUND` | 「未找到分期计划」 |
| 同一去重键重复提交 | 返回首次结清结果 | 无（去重命中） | 「结清已受理」 |
| 当期还款与结清并发（version 冲突） | 乐观锁拒绝，提示刷新 | `CONCURRENT_MODIFICATION` | 「计划状态已变化，请刷新后重试」 |
| ledger-service 结清分录失败 | 计划保持 `ACTIVE`，不释放额度 | `DOWNSTREAM_UNAVAILABLE` | 「结清失败，本次未扣款，请重试」 |

## 5. 业务规则

| 编号 | 规则 | 来源 | 优先级 | 验证点 |
|------|------|------|--------|--------|
| BR-INS-01 | 单笔消费分期金额 ≥ 100.00；账单分期 ≥ 500.00 | 模拟业务确认 | 必须 | 99.99 元被拒并返回 `INSTALLMENT_NOT_ELIGIBLE`；100.00 元可提交 |
| BR-INS-02 | 期数仅 3/6/12；月手续费率 0.60%/0.55%/0.50% | 模拟定价 | 必须 | 三档期数试算结果与定价表逐项一致；其余期数返回 `INVALID_TERM` |
| BR-INS-03 | 每期本金 = 本金/期数，最后一期吸收尾差；手续费按剩余本金×月费率，HALF_UP 2 位 | 模拟定价 | 必须 | 1000.00 元 6 期：每期本金 166.66、最后一期 166.70，合计 = 1000.00 |
| BR-INS-04 | 同一交易/同一账单只能成功分期一次；去重键唯一 | 模拟业务确认 | 必须 | 重复提交返回同一计划号，`installment_plan` 计数不变 |
| BR-INS-05 | 分期占用额度 = 剩余本金；提前结清释放 | 模拟业务确认 | 必须 | 建计划后账户分期占用 = 1000.00；结清后归零 |
| BR-INS-06 | 已逾期、已争议、已分期的交易不可分期 | 模拟风险政策 | 必须 | 三类交易入口置灰，直接调接口返回 `INSTALLMENT_NOT_ELIGIBLE` |
| BR-INS-07 | 提前结清收取剩余本金 1% 违约金，已收手续费不退 | 模拟定价 | 应该 | 剩余本金 600.00 时违约金 6.00，`settlementTotal` = 606.00 减手续费减免 |
| BR-INS-08 | 计划创建后 T+1 生效，首期计入下一账单 | 模拟业务确认 | 必须 | 创建日为 D，首期到期日落在 D+1 之后的账单周期 |

## 6. 非功能需求

### 6.1 性能、可用性与可观测性

| 维度 | 指标 | 验证方法 |
|------|------|---------|
| 性能 | 试算 p95 < 300ms；创建 p95 < 1200ms（本地 Compose） | 压测脚本打 50 并发，取 p95 |
| 一致性 | 金额全部 HALF_UP 2 位，禁止浮点；计划与还款计划金额合计一致 | 单元测试覆盖尾差；对账脚本比对合计 |
| 去重 | 创建与结清必须支持去重，重复请求返回首次结果 | 重复提交同一去重键，断言计划数与账务分录数不变 |
| 可用性 | 依赖服务不可用时返回明确错误码，不产生半完成资金状态 | 关停 ledger-service 后提交，断言无计划落库 |
| 审计 | 记录申请人、期数、本金、费率、计划号、操作时间 | 查询 audit-service 事件，字段齐全 |
| 可观测性 | 每个接口输出 traceId 与业务计划号 | 查看日志与 Micrometer 指标 |

### 6.2 安全需求

| 维度 | 要求 | 验证方法 |
|------|------|---------|
| 认证 | 所有接口需 IAM 签发的 JWT；无 token 返回 401 | 无 token 调用 6 个接口 |
| 授权 | 账户归属校验，越权一律 404；后台接口仅 `A` 角色可访问 | 用 A 客户 token 访问 B 客户计划 |
| 入参校验 | 金额、期数、枚举全部服务端校验，禁止前端推导资格 | 构造非法期数与负数金额请求 |
| 数据保护 | 日志与事件中卡号仅保留后 4 位；响应不返回完整卡号 | 抓包与日志检索卡号 |
| 防重放 | 去重键 + 30 分钟时间窗；过期键拒绝 | 重放 31 分钟前的请求 |
| 审计留痕 | 创建、结清、后台查询写审计事件，含 actor 与 payload | 查询 audit-service 事件 |

## 7. 接口与集成

| 接口 | 方向 | 说明 |
|------|------|------|
| POST `/api/v1/installments/preview` | 前端 → installment-service | 试算（不落库），返回试算令牌与明细 |
| POST `/api/v1/installments` | 前端 → installment-service | 创建分期（201，带去重键） |
| GET `/api/v1/installments?accountId=&status=` | 前端 → installment-service | 我的/账户分期列表 |
| GET `/api/v1/installments/{id}` | 前端 → installment-service | 详情 + 还款计划 |
| POST `/api/v1/installments/{id}/early-settlement` | 前端 → installment-service | 提前结清试算与执行 |
| GET `/api/v1/admin/installments?accountId=&status=&page=&size=` | 后台 → installment-service | 后台查询与导出 |
| 交易入账事件 | transaction-service → installment-service | 提供分期资格字段来源 |
| 额度占用/释放 | installment-service → account-service | 建计划占用剩余本金，结清释放 |
| 手续费收入过账 | installment-service → ledger-service | 手续费与违约金分录 |
| 分期通知 | installment-service → notification-service | 建计划、结清通知（失败不回滚） |
| 审计事件 | installment-service → audit-service | actor/action/resource/payload |

创建请求示例：

```json
{"idempotencyKey":"ins-20261027-001","accountId":"00000000006",
 "sourceType":"TRANSACTION","sourceId":"0000000000000200",
 "principal":1000.00,"termMonths":6,"agreementAccepted":true}
```

错误码清单：

| 错误码 | HTTP | 触发条件 |
|--------|------|---------|
| `INSTALLMENT_NOT_ELIGIBLE` | 409 | 金额不足、状态不支持、已逾期或争议中 |
| `ALREADY_INSTALLED` | 409 | 交易或账单已有生效计划 |
| `INVALID_TERM` | 409 | 期数不在 3/6/12 |
| `PREVIEW_EXPIRED` | 409 | 试算令牌过期或金额不一致 |
| `PRINCIPAL_EXCEEDS_LIMIT` | 409 | 本金超过可分期余额 |
| `SETTLEMENT_NOT_ALLOWED` | 409 | 计划非 `ACTIVE` |
| `AGREEMENT_REQUIRED` | 400 | 未勾选协议 |
| `INSTALLMENT_NOT_FOUND` | 404 | 计划不存在或越权 |
| `DOWNSTREAM_UNAVAILABLE` | 503 | account/ledger 调用失败 |

### 8.2 数据安全

| 维度 | 要求 |
|------|------|
| 脱敏 | 接口响应与日志中的卡号仅保留后 4 位；客户姓名按「姓 + \*」展示；JSON 落库前过滤敏感字段 |

| 类型 | 场景 | 角色 | 数据/接口 | 预期 |

## 11. 依赖与约束

### 11.1 依赖

| 依赖对象 | 用途 | 失败影响与处理 |
|---------|------|---------------|
| transaction-service | 交易状态与分期资格字段 | 入口展示重试，不进入申请流程 |
| billing-service | 账单可分期金额 | 试算失败，可重试 |
| account-service | 额度占用与释放 | 提交失败回滚，不产生计划 |
| ledger-service | 手续费与违约金分录 | 提交或结清失败回滚并告警 |
| notification-service | 建计划与结清通知 | 主流程不回滚，记录通知失败待补发 |
| audit-service | 审计事件 | 写失败进入本地重试队列 |
| IAM | 认证与角色 | 无 token 直接 401 |

### 11.2 影响分析

| 维度 | 影响 |
|------|------|
| 前台 | 交易详情、账单页、新增申请页、列表/详情页、后台查询页 |
| 后台 | 新 installment-service；transaction 分期资格、billing 可分期金额、account 额度占用、ledger 手续费收入、notification 通知、audit 审计 |
| 数据 | 2 张新表 + 账户额度视图新增「分期占用」 |
| 接口 | 6 个新接口；交易与账单响应增加分期资格字段 |
| 配置 | Compose 新服务与数据库、web-ui 代理 |
| 测试 | 试算、建计划、去重、资格拦截、提前结清、额度释放、总账分录 |
| 文档 | 本需求、API 目录、服务清单、runbook |

### 11.3 约束

- 技术栈沿用现有 Spring Boot 3 / PostgreSQL / 原生 SPA，不引入新框架。
- 建议新服务 `installment-service :8110`、库 `carddemo_installment`；并入 billing-service 的方案需评审后确定。
- 金额统一 `BigDecimal` / `numeric(12,2)`；ID 遵循现有零填充或 UUID 规范。
- 涉及余额的变更必须经 account-service；涉及会计影响必须过账 ledger-service。
- 所有写接口必须支持去重键；关键操作写审计事件。

## 12. 风险与假设

### 12.1 风险与应对

| 风险/假设 | 影响 | 应对 |
|-----------|------|------|
| 费率、违约金为模拟值，未经定价确认 | 上线后收入测算偏差 | 定价确认后仅替换定价表配置，不改代码；v1.1 前以 `PRICING_RATE_SIMULATION` 标记 |
| 分期占用额度口径（剩余本金 vs 总本金）未与账户/授权对齐 | 额度占用偏高或偏低，影响可用额度展示 | 以剩余本金为默认口径，上线前与账户/授权联合评审确认 |
| 首期生效时点 T+1 与账单周期耦合 | 首期会落入当期账单，产生重复应还 | 建计划时校验账单周期，冲突则顺延到下一周期并记录审计 |
| 试算令牌 30 分钟有效窗 | 客户停留过久提交失败 | 前端在剩余 5 分钟提示刷新试算 |
| 下游 ledger 偶发超时 | 客户重复提交 | 去重键 + 事务回滚 + 失败提示重试 |
| 假设单账户分期笔数上限 20 笔 | 超限客户无法再分期 | 上限值随定价一并确认，超限返回明确错误码 |

### 12.2 假设

- 演示环境沿用现有 Spring Boot 3 / PostgreSQL 技术栈与 IAM 角色 `U`/`A`。
- POC 不做接口级强鉴权（ADR-007），但账户归属校验必须保留。

### 12.3 待确认事项

1. 费率、违约金比例、首期生效时点（待确认：业务与定价出具正式定价表）。
2. 分期占用额度是「剩余本金」或「总本金」（待确认：与账户/授权口径对齐）。
3. 提前结清的手续费减免策略（待确认：是否按未到期期数比例减免）。
4. 账单分期与单笔分期是否允许叠加（待确认：产品与风控给出叠加规则）。
5. 单账户分期笔数上限（待确认：当前按 20 笔设计）。

## 13. 合规标注

| 维度 | 标注 |
|------|------|
| 监管（模拟） | 参照《商业银行信用卡业务监督管理办法》关于分期业务信息披露与费率明示的要求，试算页必须展示期数、费率、每期金额、总手续费。本文件为演示材料，不构成监管合规结论。 |
| 制度（模拟） | 参照行内分期业务管理办法（模拟编号 INST-POLICY-2026）：分期需客户主动申请并勾选协议。 |
| SoD（职责分离） | 定价与费率配置由定价岗维护，分期计划只能由客户或客服发起；风控/合规角色只读，不可修改计划。 |
| 隐私（模拟） | 参照《个人信息保护法》，仅采集分期必需字段（账户号、本金、期数、协议勾选记录），不采集与分期无关的个人信息；卡号日志脱敏。 |
| 审计 | 创建、结清、后台导出全部留痕，审计留存 3 年。 |
| 结论 | 模拟需求，费率与指标均为演示假设，投产前需法务、合规、定价三方会签。 |
